# GPU·CPU 정확성 우선 구성

2026-10-27. 사용자가 제공한 NoteMaker 실측 보고서 두 개를 검토하고, 같은 두 10분 WAV 샘플로 추가 확인했다. 원본 음성·기존 전사본은 변경하지 않았으며 음성·전사 내용을 이 저장소에 배포하지 않는다.

## 기본 정책

사용자 요구에 따라 속도보다 정확성을 우선한다. `LINK_PROFILE=accuracy`가 기본이며 선택한 모델을 자동으로 바꾸지 않는다. 제공된 보고서의 한국어 기술 용어 비교에서 채택한 모델은 large-v3지만, 그 결과를 모든 언어·회의에 일반화하지 않는다.

| 환경 | 기본 실행 | 자원 제어 |
| --- | --- | --- |
| 단일 NVIDIA GPU | 원본 구간별 순차 추론, float16, beam 5 | 모델·전용 워커 1개. 추가 요청은 대기 |
| NVIDIA GPU 여러 개 | 같은 순차 설정으로 원본 구간을 GPU에 분배 | GPU별 모델·워커 1개. 모델 복제·과도한 동시 실행 방지 |
| CPU 전용 | RAM이 충분하면 float32, 부족하면 int8 | 프로세스 허용 코어로 동시 작업 1~3개와 워커당 스레드를 나눔 |
| 자원이 제한된 컨테이너 | 읽을 수 있는 cgroup CPU·RAM 제한 반영 | CPU v1/v2 quota, RAM v1/v2 한도. 접근 불가 시 호스트 추정치 |

정확성 우선에서는 배치 처리와 강제 n-gram 반복 억제를 사용하지 않는다. GPU float16 모델이 들어가지 않으면 기본적으로 중단한다. 사용자가 정밀도 또는 CPU 전환을 명시했다면 그 선택을 따르며 CPU 전환·메모리로 인한 CPU int8 선택은 웹에 표시한다. CPU 전용 정상 동작과 GPU 실패 후 CPU 전환을 구별한다.

## 선택 가능한 성능 모드

- `balanced`: CUDA 배치, 모델 크기·GPU별 남은 VRAM으로 보수적인 배치 상한 1/2/4/8 선택. 지나치게 짧거나 용어 나열로 의심되는 구간은 같은 GPU의 순차 경로로 재확인.
- `throughput`: CUDA 배치 처리량 우선. 기본 재확인 생략. 정확성 우선 작업의 기본값으로 사용하지 않는다.
- `LINK_BATCH_SIZE=0`이면 성능 모드에서도 순차 처리. 정수 1~32는 상한이며 OOM 발생 시 배치를 줄여 같은 입력을 다시 처리한다.
- 배치 모드만 beam 5, no_repeat_ngram_size 4, repetition_penalty 1.1을 사용한다. initial_prompt 문장을 배치에 넣지 않고 hotwords 최대 220자만 넣는다.
- 여러 짧은 발화를 GPU에 묶어도 원본 화자·순서·시각은 유지한다. 원본 발화 안에서만 VAD 조각을 최대 30초로 묶으며, 모델이 생성한 시각 대신 원본 clip의 seek로 결과를 배정한다.

메모리 휴리스틱은 모든 GPU의 최적값을 찾는 자동 튜너가 아니다. GPU 사용률이나 배치를 무조건 높이지 않는다. 정답 전사본이 없으므로 재확인 장치 역시 모든 누락·환각을 검출하거나 정확도를 보증하지 않는다.

## 이 PC의 추가 실측

RTX 5060 Ti 16GB·RTX 3060 12GB, large-v3 float16. 제공된 10분 WAV 두 개를 각각 원본 순서의 약 30초 구간으로 나누어 처리했다. 다른 프로그램과 기존 클라이언트의 GPU 점유는 유지했다. 모델 로드·오디오 읽기는 아래 추론 시간 밖이며, 별도의 독립 워밍업은 하지 않았다. 순차 기준은 1회, 배치는 같은 로드 상태에서 2회 측정했다.

| 경로 | GPU | 배치 | 20분 음성 처리 시간 | 실시간 대비 처리량 |
| --- | --- | --- | --- | --- |
| 종전 순차 경로(정확성 우선과 같은 기본 디코딩) | 5060 Ti | 0 | 129.47초 | 9.27배 |
| 배치만 사용한 탐색 후보, 기본값으로 채택하지 않음 | 5060 Ti | 8 | 23.30 / 22.97초 | 51.51 / 52.25배 |
| 배치 + 의심 구간 순차 재확인 | 5060 Ti | 8 | 34.34 / 33.97초 | 34.94 / 35.33배 |
| 배치만 사용한 탐색 후보 | 3060 | 4 | 42.36 / 41.92초 | 28.33 / 28.63배 |

배치 후보에서는 두 샘플 모두 원본 20개 구간에 결과가 있었지만, 일부 구간의 설명 문장이 기술 용어 몇 개로 축약됐다. 단순히 빈 행이나 구간 수를 검사하는 것으로는 잡을 수 없는 차이다. 해당 구간을 동일 모델·GPU의 순차 경로로 재확인하면 설명 문장이 출력됐다. 따라서 가장 빠른 후보를 정확성 우선 기본값으로 채택하지 않았다. 재확인 후에도 순차 결과와 문장 차이가 남으므로 정확도가 같다고 주장하지 않는다.

위 처리량은 기본 정확성 모드의 개선율, 모든 GPU의 보장값, WER/CER 또는 정답 대비 정확도가 아니다. 단일·다중 GPU 처리량을 합산하지 않았으며 혼합 배치 8/4의 동시 전체 처리량도 이번에 실측하지 않았다.

## 검증 범위

- 기본 단일 GPU 정확성 모드가 배치 0이며, 축약됐던 실제 30초 입력에서 순차 설명 문장을 출력하는지 확인.
- CPU 모델의 float32·int8 실제 실행 확인(캐시된 base 모델의 짧은 오디오). large-v3의 CPU 처리량·정확도 벤치마크는 아님.
- 단위 테스트: GPU별 메모리 상한, 원본 clip·화자 배정, OOM 부분 결과 폐기/재시도, 30초 초과 음성 보존, GPU 작업 분배, CPU affinity/컨테이너 예산, CPU 스레드 분배, 정확성 모드 양자화 금지·RAM별 CPU 정밀도, 의심 구간 재확인.
- 새 Python 모듈의 wheel 및 Docker COPY 포함 여부 확인. AMD·Intel의 신규 실기 성능은 측정하지 않았으며 기존 실행 경로를 유지한다.
